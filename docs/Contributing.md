# Contributing to LevelUp

## Overview

This document defines the current engineering conventions for contributing to LevelUp.

The project is under active development. Conventions may evolve as the architecture grows.

## Requirements

- .NET SDK compatible with the project target framework
- Git
- a terminal with Unicode support
- an editor or IDE with C# support
