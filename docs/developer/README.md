# Developer

Guia de contribuição e configuração de ambiente de desenvolvimento.

**Disposição final (Sprint 31.14, EPIC 31):** esta pasta permanece intencionalmente sem documento
próprio — não é mais uma área reservada aguardando uma Sprint futura, é a decisão definitiva. As
instruções de setup (requisitos, `restore`/`format`/`build`/`test`/`run`, quality gate) já vivem em
[`README.md`](../../README.md) da raiz, seções "Requirements", "Start locally" e "Quality gate", e
são verificadas a cada reconciliação desta EPIC. Criar um segundo documento aqui duplicaria essas
seções ou fragmentaria a mesma informação em dois lugares. Se o processo de contribuição crescer
além de comandos de setup (ex.: um guia de revisão de código específico para colaboradores externos,
que hoje não existe porque este é um repositório proprietário sem colaboração externa), um documento
próprio pode ser criado então, a partir de evidência real — não antecipado aqui.
