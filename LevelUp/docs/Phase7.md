# Fase 7 — Progressão do personagem

## Objetivo

Transformar o personagem em uma representação clara da evolução real do jogador, sem introduzir combate ou bônus de classe prematuros.

## Entregas

- classe narrativa preservada;
- títulos automáticos por faixa de nível;
- tela de progressão com todos os títulos e estados de desbloqueio;
- reconhecimento profissional preservado por conquistas de projeto;
- testes das faixas de progressão.

## Títulos

| Nível | Título |
|---:|---|
| 1–9 | Aprendiz |
| 10–19 | Aventureiro |
| 20–29 | Discípulo |
| 30–39 | Adepto |
| 40–49 | Especialista |
| 50–59 | Mestre |
| 60+ | Lenda |

## Próximas evoluções

- histórico de níveis;
- evolução visual da classe;
- atributos com efeitos configuráveis;
- trilhas opcionais de especialização.
