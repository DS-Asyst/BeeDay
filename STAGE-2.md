# Etapa 2 — Domínio

## Entregue

- Abstração base `Entity` para identidade.
- Estado encapsulado nas entidades.
- Factories para `Habit`, `RecurringTask`, `Todo`, `Project` e `Profile`.
- Value objects para título, descrição, nome e apelido.
- Exceções de domínio e de estado persistido inválido.
- Validação de valores de enums.
- Compatibilidade com o esquema JSON existente.
- Mutações centralizadas em `LevelUpData`.
- Consistência entre status de projeto e conclusão da atividade.
- Testes de value objects, contadores, enums e projetos.
